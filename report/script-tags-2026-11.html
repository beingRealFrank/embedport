We checked 258 Shopify stores: 207 still use script tags

Shopify stops running storefront script tags on March 1, 2027. On November 15-17, 2026 we read the homepage source of 258 well-known direct-to-consumer Shopify stores. 207 (80%) still loaded at least one script tag; the median among those was 6, the most was 17.

Method and limits

We fetched each store's homepage once and counted the URLs in Shopify's script-tag loader. This sees online-store script tags only, not Order status page ones, and only on the homepage. The store list (432 domains tried, 258 Shopify answers) is a convenience sample of well-known brands, not a random sample of Shopify.
