We checked 134 Shopify stores: 97 still use script tags

Shopify stops running storefront script tags on March 1, 2027. On November 15, 2026 we read the homepage source of 134 well-known direct-to-consumer Shopify stores. 97 (72%) still loaded at least one script tag; the median among those was 6, the most was 15.

Method and limits

We fetched each store's homepage once and counted the URLs in Shopify's script-tag loader. This sees online-store script tags only, not Order status page ones, and only on the homepage. The store list (174 domains tried, 134 Shopify answers) is a convenience sample of well-known brands, not a random sample of Shopify.
