Elfsight widgets: is your store still loading it through a script tag?

Shopify stops running storefront script tags on March 1, 2027. Apps haven't been able to create or update them since October 1, 2026. If Elfsight widgets on your store still loads through an old script tag, whatever it adds to your storefront stops on that date unless it has been moved to a theme app extension or web pixel.

What we saw

On November 15-17, 2026 we read the homepages of 258 Shopify stores. 5 still loaded Elfsight widgets through a script tag (shy.elfsight.com), for example faithfull-the-brand.com, ghostlifestyle.com, lskd.co, oneractive.com. A script tag that still loads today is not proof that a store will break: some vendors have shipped an app embed and left the old tag behind. It does mean someone should check.

What to do

  1. Run the free checker on your homepage source to see whether Elfsight widgets is on your list.
  2. Ask Elfsight whether they ship an app embed block (theme app extension) and how to turn it on. Documentation we found: Elfsight widgets install help.
  3. Switch the embed on in your theme editor (Online Store → Themes → Customize → App embeds), and confirm the feature loads once, not twice.
  4. Only then delete the old script tag. Shopify's guide says not to delete a script tag until its replacement is confirmed running.

This is a general guide; we are not Elfsight, and the steps depend on your plan and theme.
