Shopify deadline · 105 days left

On March 1, 2027, Shopify stops running script tags on every storefront.

Whatever a script tag loads stops working that day: review widgets, loyalty bars, back-in-stock forms, affiliate tracking, fraud beacons. Apps can't create or update script tags any more (since October 1, 2026), and pinning an older API version doesn't help. Shopify isn't showing merchants a warning banner.

FAQ

What exactly changes on March 1, 2027?

Shopify stops injecting script tags into storefront pages, so anything that depends on them stops working for your store. Since October 1, 2026, apps can't create or update script tags. They can still list and delete them. Sources: Shopify developer changelog, Storefront script tags guide.

My app vendor says they've already moved to an app embed. Am I fine?

Maybe. The embed usually has to be switched on in your theme editor (Online Store → Themes → Customize → App embeds), and an old script tag record can stay on your store alongside it. Until March 1, that can load the same code twice. After March 1, an embed that was never switched on means the feature is gone. The free check shows what still loads through script tags today.

What about the Order status page?

That deadline came earlier: script tags already stopped running there for Plus stores, and Shopify's guide points to customer account UI extensions as the replacement. The audit covers it.

Is this the same as "Shopify Scripts"?

No. Shopify Scripts (the Ruby checkout scripts replaced by Functions) is a separate retirement. This is about the ScriptTag API apps use to add JavaScript to storefronts.
