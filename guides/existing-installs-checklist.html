Moving existing installs from a script tag to an app embed: a checklist

Since October 1, 2026 an app can't create or update script tags, and from March 1, 2027 Shopify stops running the ones that exist. The hard part for developers is existing merchants: Shopify staff said on the developer forum (August 25, 2026) that there is no programmatic way to switch an app embed on for existing installs. This is a practical order of operations that follows Shopify's own guidance.

1. Decide which replacement each script needs

If the script loads JavaScript that changes or adds to storefront pages, the replacement is an app embed block in a theme app extension (it works on vintage and Online Store 2.0 themes, but the merchant has to activate it per theme). If it only collects analytics or conversion data, build a web pixel, which needs no theme activation. Order status page scripts follow an earlier schedule and move to customer account UI extensions. Scripts in admin-created custom apps have no extension replacement; the options are theme code or a real app.

2. Ship the embed next to the script tag, not instead of it

Shopify's guide says not to delete a script tag until you have confirmed its replacement is running. If both run, the script loads twice, so make the script idempotent (guard on a global flag) before you ship the embed.

3. Get merchants to switch it on

Send them to the theme editor with your embed pre-selected using the activation deep link in Shopify's guide, from in-app messaging and email. Activation is per theme: if a merchant publishes a different theme, the embed is off there and the check has to be repeated.

4. Confirm it is on before removing the tag

Track per shop whether the embed is live on the published theme and keep the script tag until it is. Then call scriptTagDelete (still supported). After March 1, 2027 leftover script tag records have no effect, so there is no urgency to delete them for correctness, only to avoid the double load.

5. Clean up

Once all installs are moved, remove the write_script_tags scope. Merchants on legacy themes need the embed too; the embed block supports them.

Sources: Shopify's storefront script tag guide, the changelog, and the developer forum thread.
