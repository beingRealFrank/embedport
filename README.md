# Embedport

https://beingrealfrank.github.io/embedport/

A free check that shows which of a Shopify store's script tags stop running on March 1, 2027, and what replaces each one. It runs in the browser, and there is also a one-file Python CLI (`scripttag_check.py`). Fixed-price audits, store migrations and app ports.

Not affiliated with or endorsed by Shopify Inc.
